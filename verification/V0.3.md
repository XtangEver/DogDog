# v0.3.0 自主检索 Codex 历史验证

日期：2026-10-31。测试使用隔离配置、合成轨迹；真实服务仅覆盖 OpenAI Responses，不代表真实私有任务上的诊断质量或建议效果已验证。

## 实现与兼容

- 设置中保存轨迹目录及当前服务的片段发送权限；旧配置默认未授权，需要确认一次。Enter 不再生成授权弹窗，发送预览由用户主动打开。
- 新讨论、重启、新文件及模型名变化不重复确认；服务/目录变化需要重新勾选。主进程核验权限，撤权或范围变更清空后续模型上下文，历史证据保留本机。
- `discover_sessions` 发现获准的当前与归档会话；`search_traces` 默认搜索目录及有效快照，命中自动建立证据快照，`read_trace` 读取上下文。来源 ID 不复用、引用绑定内容哈希及原始行号。
- 工具定义与快照操作位于 `src/core/trace-tools.ts`，异步执行入口位于 `src/core/tool-runtime.ts`，目录及服务策略位于 `src/core/access-policy.ts`，文件清单与解析缓存位于 `src/core/trace-library.ts`；循环、会话持久化和三协议适配分别保留原模块。
- 参考 dsh 的工具、循环、会话和模型适配分层，未引入 dsh/Cordis 依赖。参考：https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md 。
- 旧版复盘及 v0.2 对话文件可继续读取。旧 `grant` 字段保留解析兼容但不再授予发送权限；移除 `authorizeConversation` IPC 和临时授权票据。新增设置字段 `traceRoots`、`allowTraceSend`；快照增加可选 `libraryRoot`，对话增加可选 `accessFingerprint`、`excludedPaths`。

## 弹窗核对

原代码的 Enter 路径总是先调用预览，再比较“模型/服务/快照集合”指纹。首次讨论、来源新增/刷新/撤销或模型变化会要求确认；无法仅凭代码认定来源和设置完全不变时每个 Enter 都会弹窗。v0.3 移除了该发送路径，通过连续发送、新讨论、重启、快照刷新测试确认不再出现旧弹窗。

## 自动化验收

- `npm run typecheck`、`npm test`、`npm run test:e2e`、`npm run build` 和 Prettier 检查。
- 新增单元场景：中文正文、标题/项目/日期过滤，当前与归档来源，155 份轨迹及分页，返回片段才建立快照，缓存跨实例复用/损坏重建/增量更新，空结果/损坏文件/缺失目录，路径越界/目录联接/链接根目录，解析途中与工具执行取消，三协议自主搜索读取引用，持久授权和来源排除。

- 结果：48 项单元测试通过，16 项桌面测试通过；类型检查、构建、Prettier 与 `git diff --check` 均通过。截图均为合成数据，历史 v0.1/v0.2 截图保持原版本。

## 真实模型验收

命令：`node scripts/check-library-real.mjs`。需要环境变量 `GLM_API_KEY`；仅隔离验证配置读取该变量，正常应用仍无环境密钥回退。

证据：[真实服务汇总](v03-real-library.json)、[真实 GLM 截图](screenshots/v03-real-glm.png)。自然提问为“之前鼠标移动缓慢如何解决？请查证原始记录和复测情况，简短回答并引用原文。”，没有预先关联文件或在问题中指定工具。

- 模型自行调用 `discover_sessions`、`search_traces`、两次 `read_trace`，3 次模型请求后完成回答；引用涉及当前及归档两份快照。
- 干扰轨迹正文未进入请求；没有读取或发送真实私有轨迹。
- 重启后对话及来源恢复，直接 Enter 继续，无重复确认。
- 原始合成文件及正式应用配置哈希保持不变。完整请求历史仅保留本机、被 Git 忽略。

## 限制

- 首次查询需扫描并解析授权目录，之后复用按大小、mtime 和 ctime 校验的缓存；缓存是文件级解析缓存，正文检索采用字面子串匹配，没有向量检索或全文数据库。大规模历史的首次响应性能尚未基准测试。
- 单文件上限 100 MB，每次扫描最多 30000 项、12 层目录；返回每页 20 项，超限、缺失或损坏有明确警告。标题取解析器提取的首条用户消息，Agent 尚不使用界面列表中的重命名标题索引。
- 解析缓存和证据快照包含未加密的本机正文；撤权阻止后续模型发送，不删除本地历史。目录链接/联接禁止，原始轨迹只读。
- 每轮 12 次请求、单请求 120 秒及完整字符预算沿用现有约束；取消不保证远端停止计算。结构与行号校验不能保证结论语义正确。
