# DogDog v0.2.0 验证记录

日期：2026-10-30（Asia/Shanghai）。

## 实现结果

- 持续对话为默认入口；支持无轨迹咨询、多来源固定快照、原生工具循环、追问后续聊、证据原文、报告版本与重启恢复。
- 来源范围按对话确认，变更后重新授权；移除/替换来源时保留历史证据并重置后续模型上下文。运行中阻止重复发送、修改设置/来源或启动旧版诊断。
- 原始轨迹只读；旧版复盘及原有数据继续使用。取消、断流、预算耗尽和无效引用保留未完成状态，不自动重发。

## 真实模型验证

- 命令：`node scripts/check-agent-real.mjs`；数据与网络汇总见 [v02-real-agent.json](v02-real-agent.json)，截图见 [v02-real-glm.png](screenshots/v02-real-glm.png)。
- 模型：`GLM-5.3`；协议：OpenAI Responses；完整地址：`https://open.bigmodel.cn/api/v1/responses`。8 次真实请求均返回 HTTP 200、`text/event-stream`。
- 覆盖：无轨迹讨论 → 模型调用 `ask_user` → 关闭应用 → 重启后补充回答并继续 → 关联两份合成轨迹 → 多轮只读查证 → 双来源引用 → 保存报告 → 再次重启恢复。
- 跨轨迹阶段：5 次模型请求，调用 `list_sources`、6 次 `search_traces` 及 2 次 `read_trace`；最终引用覆盖两份来源的原文 L2–L5，并通过本轮已读取证据检查。
- 密钥由隔离测试应用主进程从 `GLM_API_KEY` 读取并加密写入临时配置，不经渲染进程设置、不写入报告。测试结束清理临时配置；原用户配置及两个源文件的哈希不变。
- 桌面取消用例验证部分文本在分析结束前可见；状态更新采用顺序推送，避免异步读取覆盖已显示的流式片段。完整合成对话和请求历史保留为本地忽略文件，不纳入 Git。

## 验证边界与协议依据

- 真实测试只发送合成数据，没有发送用户的私有轨迹；真实 Anthropic 与 Chat Completions 服务未验证。
- 引用校验只证明对应记录被读取、引用存在，不证明解释正确或建议有效；跨任务规律仍是待验证假设。
- 未添加长期记忆、自动用户画像、源码访问、命令执行或后台监控。关联快照及完整请求历史保存在未加密的本地对话文件中；大文件和长历史仍受内存及字符预算限制。
- 安装包未签名；构建与直接启动的验证不等同于执行安装/卸载向导。
- 协议实现参照 [official OpenAI documentation：Function calling](https://developers.openai.com/api/docs/guides/function-calling)、[Anthropic：Streaming messages](https://platform.claude.com/docs/en/build-with-claude/streaming) 与 [智谱：Response API 兼容](https://docs.bigmodel.cn/cn/guide/develop/responses/introduction)。Responses 按终止事件判断结束，不依赖 `[DONE]`。
