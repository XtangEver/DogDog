# 来源、改编与隐私

本套件由合成材料和脱敏历史改编组成。无原始私有轨迹、真实密钥、私人项目正文或真实用户会话标题进入共享资产。案例内的路径、人名、项目、结果均为合成；历史来源只用于提炼问题结构，不把原始讨论复制为检索夹具。

## 已确认产品决策

- 本聊天（2026-10-31）：评测先行、十二体系、电脑Agent执行与独立复核、协作顾问＋效果闭环、合成＋脱敏历史改编、完整包＋抽样试跑。
- 仓库 AGENTS.md：持续讨论为中心，轨迹可选、多来源证据、只读与授权边界、长期档案后续增量。
- verification/V0.3.md：当前回归及合成真实服务验证的范围；不证明真实任务质量或长期收益。
- verification/retest-v03/REPORT.md：回答冗长和无关泛化、桌面入口版本偏差、评分脚本误选引用的历史种子。

各任务 provenance.sources 给出可核对的仓库路径与行号；这些来源不是私有事实底稿。不要从历史测试通过推断当前运行状态，试验必须记录实际版本和观察。

## 控制与验收

1. 不把评测执行者自己的Codex/Claude日志、评分底稿、任务卡或旧运行结果放入DogDog检索目录。
2. fixture只用新隔离根，正式配置不读写；原文件哈希在运行前后比较。
3. 原始请求和截图仅含已检查合成内容时才可进入reports；完整运行产物默认Git忽略。
4. case split按家族隔离；同源反事实对留在同侧。共享仓库中的holdout不是秘密答案，真正独立验收使用分包及新上下文。
5. 后续若加入真实历史，必须另行锁定材料范围、保存位置及允许接收数据的服务，本v1不预授权。
